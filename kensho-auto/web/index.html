初期設定

GitHub の fine-grained Personal Access Token を使って、非公開リポジトリのデータを直接読み書きします。トークンはこの端末のブラウザ（localStorage）にだけ保存されます。

必要な権限：対象リポジトリのみ / Contents: Read and write / Actions: Read and write / Metadata: Read
